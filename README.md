# demovie

**Your agent animates. demovie makes it true.**

demovie is an open-source (MIT) toolkit that gives AI coding agents what they need to make accurate, on-brand motion-graphics videos of a real web app: real captures, brand tokens, a deterministic renderer, machine-checked QA, license-clean audio, and an Agent Skill that encodes the craft.

> Work in progress. See [SPEC.md](SPEC.md) for the specification and [PROGRESS.md](PROGRESS.md) for the build status.

## Develop

```bash
pnpm install
pnpm build
pnpm verify
```
