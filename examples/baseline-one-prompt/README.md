# Baseline: a "one-prompt" video (for comparison only)

This composition was written the way viral one-prompt product videos are made: from a single prompt ("Make a 30 s
launch video for Harborly's new Projects board"), **without** captures, the glossary or the brand file. Everything in
it is imagined: the dashboard is redrawn with divs, the metrics and features are invented, and it uses the usual
clichés (HUD and timecode labels, neon purple-blue gradients, generic "Done" chips, constant cuts, a logo-only ending).

It exists only for `docs/media/grounded-vs-generic.mp4`. It is not a reference composition, and `demovie qa` fails on
it — which is the point.
