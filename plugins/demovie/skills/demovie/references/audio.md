# Audio: music, SFX, voiceover, captions, mix

All audio is generated locally, generated by a provider with the user's own key, or imported by the user with an
explicit license flag. **Never download audio.** Every file gets an entry in `audio/provenance.json`; QA `DM-A04`
fails on any audio file without one.

## Music (free, deterministic)

```bash
npx demovie audio music <slug> [--mood uplifting|tech|calm|energetic|minimal] [--bpm 80-140] [--key "F#m"] [--seed s]
```

- Writes `audio/music.wav` (48 kHz stereo) and `audio/beats.json`, and sets `video.json` `audio.music`.
- Defaults: mood from the style (clean → uplifting, bold → energetic, soft → calm, editorial → minimal,
  terminal → tech); BPM from `storyboard.md` frontmatter; seed = the slug (same seed, same music).
- Structure follows the storyboard: intro (first shot), build, main, outro with an **ending hit on the final shot**
  (a bar line lands exactly on it). Re-run after changing shot timing.
- `beats.json`: `{ bpm, offset, beats[], bars[], sections[] }` → `v.beat(n)` / `v.bar(n)` in the composition.
- Paid alternative: `--provider elevenlabs` (needs `ELEVENLABS_API_KEY`, prints a cost estimate, needs `--yes` after
  the user approves). A licensed track: `npx demovie add track.mp3 --licensed --describe "<license>"`, set
  `audio.music.src` to `"assets/track.mp3"`, then `audio music <slug> --provider file` for the beat grid.

## SFX (bundled, CC0)

```bash
npx demovie audio sfx --list
```

`whoosh-short`, `whoosh-long`, `swipe`, `click`, `soft-click`, `pop`, `tick`, `type-key`, `riser-2s`, `impact`,
`shimmer`, `notification`. Cue them in `video.json`:

```json
"audio": {
  "sfx": [
    { "name": "whoosh-short", "at": 3.05, "gain": -16 },
    { "name": "click", "at": 9.85, "gain": -14 },
    { "name": "type-key", "at": 11.45, "gain": -22 },
    { "name": "shimmer", "at": 30.55, "gain": -18 }
  ]
}
```

Match cues to what happens on screen: `click` at each `cursor.click` time, one `type-key` per typed character
(`at + i / cps`), `whoosh-short` slightly before a push or crossfade, `shimmer`/`impact` on the logo. Less is more;
keep gains between −12 and −22 dB.

## Voiceover (optional, paid, the user's key)

```bash
npx demovie audio voice <slug> [--provider elevenlabs|openai] [--voice <id>] [--model <id>] [--script vo.txt]
```

- Only when a provider is configured (`audio.voice` in config or `--provider`) **and** the user approved the cost.
  The command prints the estimate first and needs `--yes` (or an interactive confirmation) to spend anything.
- Lines come from the storyboard's VO column verbatim (ids `vo-<shot #>`, starting with their shot), or from
  `--script` (one line per VO line; optional `[12.5]` start prefix).
- Results are cached by provider/model/voice/text in `.demovie/.cache/voice/`; re-runs of unchanged lines are free.
- Writes `audio/vo-*.mp3|wav`, `audio/voice.json` (lines with start, duration and word timings; OpenAI timings are
  marked `estimated`), `audio/captions.vtt` and `.srt`, and sets `video.json` `audio.voice`.
- Keep VO ≤ 2.6 words/s; lines must not overlap or run past the end (QA `DM-S02`).
- Keys: `ELEVENLABS_API_KEY`, `OPENAI_API_KEY` in the environment or `.demovie/.env` — never in config or code.

## Captions

- Burned in by the runtime: `captions(v, { style: "clean" | "bold" | "karaoke" })` in main.js. They show only for
  formats in `video.json` `captions.burnIn` (default 9:16) when there is VO, as cues of ≤ 7 words.
- `render` also writes `out/captions.vtt` and `out/captions.srt`.

## Mix

```bash
npx demovie audio mix <slug>
```

Music at its `gain` (default −14 dB), ducked −8 dB under VO (150 ms attack, 400 ms release), faded out over the last
second; VO at its starts; SFX at their cues; then two-pass loudness normalization to `video.json`
`audio.loudness` (default −16 LUFS, −1.5 dBTP) → `audio/mix.wav`. Run it after any audio change and before `render`
(QA `DM-S01` measures the mix: ±2 LU warns, true peak above −1 dBTP errors).
