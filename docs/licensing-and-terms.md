## Your AI agent and your subscriptions

demovie **never**:

- implements a login to an AI vendor;
- reads, stores or proxies subscription tokens, cookies or session files;
- embeds an agent SDK that uses consumer-subscription authentication.

`demovie make` only starts agent CLIs that you installed and signed in to yourself, the same way you would start them
in your terminal. In CI, the GitHub Action passes through API keys you configure as secrets (`ANTHROPIC_API_KEY`,
`OPENAI_API_KEY`) — API keys, not subscriptions. Whether your plan allows a given use is between you and your vendor.

demovie's name and logo don't use "Claude", "Codex" or "Cursor"; it describes compatibility ("works with Claude
Code").

## Paid APIs

Voiceover (ElevenLabs or OpenAI) and ElevenLabs music use **your** API key and bill your account. demovie prints the
estimated cost and waits for your confirmation (`--yes`) before any paid call, caches results so unchanged lines are
never paid twice, and never logs keys.

## Media

demovie never downloads audio or media for your videos. Music is synthesized locally, SFX are generated, voice comes
from your provider, and anything else must be imported with `demovie add --licensed`. Every audio file has a
`provenance.json` entry and QA (`DM-A04`) fails on audio without one.

## Why not Remotion?

Remotion is a great project, but it isn't open source in the OSI sense: it is free for individuals, non-profits and
companies with up to three employees, and larger for-profit companies need a paid company license (its `LICENSE.md`,
checked 2026-10-02). That doesn't fit an MIT toolkit meant to be used anywhere. demovie uses plain HTML + GSAP compositions rendered by its own
frame-stepping renderer on Playwright and your system ffmpeg.

## GSAP

GSAP, plugins included, is free for commercial use under the Standard "No Charge" GSAP License (effective 2025-04-30,
checked 2026-10-02). The license excludes tools that let people build visual animations without code in a way that
competes with Webflow's visual animation builder. demovie is a code-first toolkit: agents and developers write the
animation code, so it isn't such a tool. demovie depends on the official `gsap` package and serves it locally to
compositions. If you build a product on top of demovie, read the GSAP license yourself.

## ffmpeg

demovie uses the ffmpeg on your system and never bundles it (common ffmpeg builds include GPL components).
