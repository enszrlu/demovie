# Changelog

Release notes are written by [changesets](https://github.com/changesets/changesets) for each published package:

- [`demovie`](packages/cli/CHANGELOG.md): the CLI, MCP server, Agent Skill and plugin.
- [`@demovie/runtime`](packages/runtime/CHANGELOG.md): the composition runtime served to videos.

Both packages are versioned together. Every pull request that changes what users get adds a changeset
(`pnpm changeset`); see [.changeset/README.md](.changeset/README.md).
